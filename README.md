# Personal Website Portfolio

A responsive personal portfolio website showcasing my projects, skills, and development journey as a Computer Science student and aspiring software engineer.

🌐 Live Site: [ahadalkozai.com](ahadalkozai.com)

---

## Overview

This website was built as an evolving personal project to practice front-end development, UI design, and project organisation. It serves as a central hub to display my work, technical skills, and experimentation with web technologies.

The project has been iteratively improved over time, with multiple redesigns, new sections, and performance and UI enhancements.

---

## Features

- Multi-page portfolio structure (Home, Profile, Projects, Skills, Contact)
- Responsive design for mobile, tablet, and desktop devices
- Interactive UI elements and button behaviours
- Dynamic project showcase section
- Skills section with technology logos and categorisation
- Custom navigation bar with mobile-friendly layout
- Particle.js animated background on homepage
- Improved UI styling including blur effects and layout refinements
- Smooth navigation and structured page transitions

---

## Technologies Used

- HTML5
- CSS3 (including responsive design and custom styling)
- JavaScript (DOM interactions and UI logic)
- Particle.js (background animation effects)

---

## Key Improvements Over Time

This project has gone through multiple iterations, including:

- Addition of new pages (Projects, Skills, Profile, Contact)
- UI/UX improvements (navbar redesign, spacing fixes, visual consistency)

- Continuous updates to project and skills content
